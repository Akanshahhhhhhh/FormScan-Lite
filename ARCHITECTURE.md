## 1. Dataset

Official **labelled** release of IIIT-INDIC-HW-WORDS (ilocr.iiit.ac.in).
Do **not** use the ICDAR 2021 competition (`/ihtr/`) downloads: its test
set has no labels, and its validation file is a small non-official sample.

Layout (inside the repo, git-ignored):

```
data/<script>/
├── train/  <annotation>.txt  + images
├── val/    <annotation>.txt  + images
└── test/   <annotation>.txt  + images
```

Annotation filenames differ between splits, so each one is written out in
`config.yaml`. **Path rule (FIXED):** image = folder containing the
annotation file / path written in the line.

## 3. Split hygiene — FIXED

- Exclusion lists are generated by `src/make_excludes.py` and committed in `splits/`
- Val drops anything byte-identical to test or train. Train drops anything identical to test
- **Test is never filtered**
- Words with characters unseen in train are skipped in train/val and **kept in
  test**, where they count as errors. Dropping them would inflate accuracy

## 4. Character sets — deliberately different per script

- Built from **train only** by `src/charset.py`
- Index 0 = CTC blank
- Saved to `models/charset_<script>.json` and used by training, eval and Flask
- Bengali: **88 classes** (87 chars + blank)

Each `.tflite` ships with its charset JSON. Never hardcode an alphabet size.

## 5. Model I/O — FIXED

```
input  : float32 (1, 1, 32, 128)
output : float32 (1, T, num_classes)     # CTC; num_classes differs per script
decode : greedy CTC, blank = 0           # src/dataset.py::ctc_greedy_decode
```

## 6. New-script checklist (run in order)

1. Annotation check: line counts match paper; 0 missing labels; 0 missing images
2. `python src/charset.py --script <script>`, then inspect the rarest characters
3. `python src/make_excludes.py --script <script>`, then record overlaps here
4. Commit `splits/` and the updated tables above
